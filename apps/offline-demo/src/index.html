    评测重点

    两种交付模式，一条可演进的后端链路

    离线版用于立即演示交互与规则可解释性；服务版保留政策获取、审核发布、缓存和 API 的替换入口。

    离线 Demo

    浏览器本地测算

    静态政策快照 + 共享规则引擎 → 本地结算单。无网络请求，不表示实时政策。

    服务版

    API 统一执行业务规则

    页面 → 计算 API → 用例层 → 政策仓库 / TTL 缓存 → 审计记录。浏览器不导入政策比例，也不复制公式。

    政策治理

    AI 只生成待审核草稿

    原始政策 → AI/OCR 提案 → 人工审核 → 版本化发布 → 缓存失效。AI 不可直接发布，不可决定报销结果。

    MVP → 生产替换点：本地 JSON 政策仓库可替换为版本化数据库；内存 TTL 可替换为 Redis；演示提取器可替换为受控采集与模型服务；应用用例、API 契约与规则引擎保持不变。
